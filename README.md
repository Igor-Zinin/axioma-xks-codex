We are not building a game platform. We are testing whether game knowledge can be compiled into playable, provable, machine-readable objects.
# game-codex
Фабрика проверяемых игровых знаний: превращает отдельные игровые правила и механики в Playable Knowledge Objects — интерактивные объяснения, симуляции, доказательства, квизы, медиа и машиночитаемые объекты знаний для людей и AI.
